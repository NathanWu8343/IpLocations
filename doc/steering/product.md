## Product Purpose

IpLocations.Api 是一個 IP 位址地理位置查詢服務，提供 RESTful API 端點，讓應用程式能夠快速查詢 IPv4 位址對應的國家/地區資訊。

此服務解決的核心問題：
- 應用程式需要根據使用者 IP 位址判斷其所在國家/地區
- 需要高效能、低延遲的 IP 地理位置查詢能力
- 需要可擴展且易於整合的 API 服務

## Target Users

| ------------------ | ---------------------------------------- | -------------------------------------------------- |
| 應用程式開發者     | 開發需要 IP 地理位置功能的應用程式       | 快速整合 IP 查詢功能，取得準確的國家/地區資訊     |
| 系統整合工程師     | 負責將 IP 查詢服務整合至現有系統         | 使用標準 REST API 介面進行整合，確保服務穩定性    |
| 資料分析人員       | 分析使用者地理分布與行為                 | 取得準確的 IP 地理位置資料，支援業務決策與分析    |

## Key Features

1. **IPv4 位址查詢**：接受 IPv4 格式的 IP 位址，回傳對應的國家代碼（如 TW、CN、CA）
2. **高效能查詢**：使用 Redis Sorted Set 資料結構，支援快速範圍查詢
3. **RESTful API**：提供標準化的 HTTP API 介面，易於整合
4. **Swagger 文件**：內建 API 文件介面，方便開發者查閱與測試
5. **容器化部署**：支援 Docker 容器化部署，簡化部署流程

## Business Objectives

4. **可維護性**：清晰的程式碼結構，完整的測試覆蓋

## Glossary

- **IP 位址 (IP Address)**：網際網路協定位址，用於識別網路上的裝置
- **IPv4**：第四版網際網路協定，使用 32 位元位址格式（如 192.168.0.1）
- **國家代碼 (Country Code)**：ISO 3166-1 alpha-2 雙字母國家代碼（如 TW、US、CN）
- **IP 範圍 (IP Range)**：一段連續的 IP 位址區間，通常屬於同一個國家或地區
- **圖資 (IP Database)**：IP 位址與地理位置的對應資料庫，本專案使用 IP2Location Lite
