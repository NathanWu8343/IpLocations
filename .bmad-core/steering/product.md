## 產品目的
IpLocations.Api 是一個高效能的 IP 地理位置查詢服務，專門用於根據 IPv4 位址快速查詢對應的國家代碼。此服務解決了應用程式需要識別使用者或請求來源地理位置的常見需求，提供毫秒級的查詢回應時間。

## 目標使用者
**主要使用者**: 需要 IP 地理位置資訊的應用程式開發者

**使用場景**:
- 內容本地化服務 (根據地理位置顯示不同內容)
- 安全性分析 (偵測異常登入位置)
- 流量分析與統計 (了解使用者地理分布)
- 存取控制 (基於地理位置的限制)
- 廣告投放與定位

**使用者需求與痛點**:
- 需要快速、可靠的 IP 查詢服務
- 希望避免維護複雜的 IP 資料庫
- 需要簡單易用的 RESTful API 介面
- 要求低延遲、高併發處理能力

## 主要功能

1. **IPv4 地理位置查詢**: 接受 IPv4 位址，返回對應的國家代碼 (ISO 3166-1 alpha-2 格式，如 TW、CN、CA)
2. **高效能查詢機制**: 使用 Redis Sorted Set 實現快速 IP 範圍查詢，支援毫秒級回應
3. **RESTful API 介面**: 提供標準化的 HTTP API，易於整合到各種應用程式
4. **Swagger API 文件**: 內建互動式 API 文件，方便開發者測試與整合
5. **容器化部署**: 支援 Docker 容器化部署，便於橫向擴展與維護

## 商業目標

- **提供可靠的查詢服務**: 確保高可用性與穩定性，滿足生產環境需求
- **支援高併發查詢**: 能夠處理大量並發請求，適應流量高峰
- **降低整合成本**: 透過簡單的 API 介面，降低開發者整合難度與時間成本
- **資料準確性**: 使用 IP2Location Lite 資料集，確保地理位置資訊的準確性

## 成功指標

- **查詢回應時間**: < 100ms (P95)
- **API 可用性**: > 99.9% uptime
- **查詢準確率**: > 95% (基於 IP2Location Lite 資料準確度)
- **併發處理能力**: 支援每秒 1000+ 查詢請求
- **錯誤率**: < 0.1% (非 IP 格式錯誤導致的系統錯誤)

## 產品原則

1. **效能優先**: 採用高效能的資料結構與查詢演算法，確保低延遲回應
2. **簡單易用**: API 設計簡潔明瞭，降低學習曲線與整合成本
3. **可靠穩定**: 透過完整的測試覆蓋與錯誤處理，確保服務穩定性
4. **可擴展性**: 架構設計支援水平擴展，滿足未來流量成長需求

## 監控與可見性

- **儀表板類型**: 目前未實作專用儀表板，建議透過 APM 工具 (如 Application Insights、Prometheus) 監控

## 未來願景

### 潛在增強功能
- **IPv6 支援**: 擴展至 IPv6 位址查詢 (已列入規劃)
- **更詳細的地理資訊**: 除了國家代碼，提供城市、經緯度等更詳細資訊
- **快取策略優化**: 實作多層快取機制，進一步提升查詢效能
- **批次查詢 API**: 支援一次查詢多個 IP 位址
- **流量限制機制**: 實作 API 速率限制，防止濫用 (每人每秒 10 次查詢)
- **資料更新機制**: 自動化 IP 資料庫更新流程
- **監控儀表板**: 建立即時監控儀表板，追蹤服務健康狀態與使用統計
- **分析功能**: 提供查詢統計、地理分布分析等功能
