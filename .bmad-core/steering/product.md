# 產品指導文件：IpLocations API

本文檔定義了 IpLocations API 的產品願景、目標使用者、核心功能與成功指標，為所有開發工作提供清晰的方向。

---

## 1. 產品願景 (Product Vision)

打造一個**高效能、高可用且易於整合的 IP 地理位置查詢 API**。我們的目標是為開發者提供一個輕量級、反應迅速的解決方案，以應對需要根據 IP 位址進行初步地理定位的常見場景。

## 2. 核心問題與目標使用者 (Core Problem & Target Audience)

-   **核心問題**：許多應用程式（如電子商務、內容平台、網路安全工具）需要一種快速且可靠的方式來判斷使用者 IP 位址所在的國家，以便進行內容在地化、流量分析、風險評估或規則設定。
-   **目標使用者**：主要為**應用程式開發者**與**系統架構師**，他們需要在自己的服務中整合 IP 地理位置查詢功能，並對查詢效能與系統穩定性有較高要求。

## 3. 核心功能 (Key Features)

-   **IP 到國家查詢 (IP-to-Country Lookup)**：
    -   提供一個 RESTful API 端點。
    -   輸入一個 IPv4 位址。
    -   回傳對應的國家代碼（例如："TW", "US", "CN"）。
-   **高效能查詢**：後端利用 Redis 進行最佳化，確保低延遲的回應。
-   **高可用性**：系統設計旨在確保服務的穩定性與持續可用性。
-   **簡易整合**：提供基於 OpenAPI (Swagger) 的標準化 API 文件，方便開發者理解與整合。

## 4. 業務目標 (Business Goals)

-   **短期目標**：成為團隊內部需要 IP 查詢功能時的首選工具，並確保其穩定運行。
-   **長期目標**：有潛力發展為一個公開的微服務，為更廣泛的應用提供支援，並達到每日處理百萬次以上查詢的能力。

## 5. 成功指標 (Success Metrics)

-   **效能**：
    -   P99 查詢延遲（從收到請求到發出回應）**低於 100 毫秒**。
-   **可靠性**：
    -   系統正常執行時間 (Uptime) **大於 99.9%**。
-   **品質**：
    -   程式碼的測試覆蓋率維持在**高水準**，特別是核心查詢邏輯。
-   **採用率**：
    -   （若作為內部工具）被多個關鍵專案成功整合。
    -   （若作為公開服務）API 呼叫量持續穩定成長。
