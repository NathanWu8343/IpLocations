### **需求文件: `add-statistics-api`**

#### **1. 願景與目標**

此功能旨在提供一個 API 端點，以追蹤和顯示每個國家代碼（Country Code）被查詢的次數。這將有助於了解服務的使用情況與地理分佈趨勢，支持未來的業務決策與效能優化。

#### **2. 使用者故事**

*   **身為** 系統管理員，
    **我想要** 透過 API 取得每個國家被查詢的次數統計，
    **以便** 監控服務的熱點區域與流量分佈。

*   **身為** 開發人員，
    **我想要** 每次 IP 地區查詢成功時，自動累計對應國家的計數，
    **以便** 確保統計資料的即時性與準確性。

#### **3. 驗收標準 (Acceptance Criteria)**

**場景 1: 成功查詢 IP 地區時，累計統計次數**
*   **WHEN** 使用者透過 `GET /api/IpLocations?ip={ip_address}` 成功查詢到一個 IP 的國家代碼（例如 "TW"），
*   **IF** 該次查詢是有效的，
*   **THEN** 系統應在後端自動將 "TW" 國家的查詢計數加一。

**場景 2: 查詢無效 IP 時，不累計統計次數**
*   **WHEN** 使用者使用一個無效或找不到對應地區的 IP 進行查詢，
*   **IF** API 回傳 `404 Not Found`，
*   **THEN** 系統不應累計任何國家的查詢次數。

**場景 3: 取得所有國家的統計資料**
*   **WHEN** 使用者請求 `GET /api/statistics` 端點，
*   **IF** 系統中有統計資料，
*   **THEN** 系統應回傳一個 JSON 物件，其中包含所有被查詢過的國家代碼及其對應的查詢次數。
    *   **範例回應**:
        ```json
        {
          "TW": 1024,
          "CA": 512,
          "CN": 256
        }
        ```

**場景 4: 系統中尚無任何統計資料**
*   **WHEN** 使用者請求 `GET /api/statistics` 端點，
*   **IF** 從未有任何成功的 IP 查詢，
*   **THEN** 系統應回傳一個空的 JSON 物件 `{}`。
